## 📞 Mantenimiento de Docs

### Cómo Actualizar Documentación

1. **Cuando hagas cambios importantes:**
   - Actualiza documento relevante
   - Agrega fecha en "Última actualización"
   - Haz commit con `docs:` prefix

2. **Cuando descubras nuevo problema:**
   - Agrega sección en TROUBLESHOOTING_GUIDE.md
   - Documenta causa y solución
   - Incluye ejemplos

3. **Cuando agregues endpoint:**
   - Agrega fila en API_ENDPOINTS_REFERENCE.md
   - Incluye ejemplo de uso
   - Documenta parámetros y respuestas
